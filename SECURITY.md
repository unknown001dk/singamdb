# Security Policy

## Supported Versions

We actively maintain and support security patches for the following versions of SingamDB:

| Version | Supported          |
| ------- | ------------------ |
| 3.x.x   | :white_check_mark: |
| 2.x.x   | :x:                |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in SingamDB, please do **NOT** open a public GitHub issue.

Instead, please report security issues privately:
1. Email details to **dk9232525@gmail.com** with subject `[SECURITY] <Brief Description>`.
2. Include reproduction steps, environment details, proof-of-concept payload, and any suggested mitigations.
3. We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a patch.
4. Security advisories will be published alongside patched releases with credit to the reporter.
