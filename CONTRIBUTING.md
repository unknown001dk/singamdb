# Contributing to SingamDB

Thank you for your interest in contributing to **SingamDB**!

We welcome contributions from developers of all skill levels. Whether you are fixing a bug, adding a new feature, optimizing execution performance, or improving documentation, your help is appreciated.

## Quickstart for Contributors

```bash
# 1. Clone the repository
git clone https://github.com/unknown001dk/singamdb.git
cd singamdb

# 2. Build the solution
dotnet build SingamDB.sln

# 3. Run all unit and integration tests
dotnet test SingamDB.sln
```

Please make sure all tests pass before submitting a Pull Request!
